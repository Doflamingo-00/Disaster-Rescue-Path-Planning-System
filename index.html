💾 SQL DDL Schema Definitions
CREATE TABLE users (user_id VARCHAR(10) PRIMARY KEY, name VARCHAR(50), role VARCHAR(30), status VARCHAR(20)); CREATE TABLE incidents (incident_id VARCHAR(10) PRIMARY KEY, disaster_type VARCHAR(30), location_id VARCHAR(10), severity VARCHAR(20), description TEXT, status VARCHAR(20), created_at TIMESTAMP); CREATE TABLE locations (location_id VARCHAR(10) PRIMARY KEY, name VARCHAR(50), type VARCHAR(30), latitude FLOAT, longitude FLOAT, status VARCHAR(20)); CREATE TABLE edges (edge_id VARCHAR(20) PRIMARY KEY, from_location VARCHAR(10), to_location VARCHAR(10), distance FLOAT, travel_time FLOAT, risk FLOAT, capacity INT, status VARCHAR(20)); CREATE TABLE rescue_requests (request_id VARCHAR(10) PRIMARY KEY, incident_id VARCHAR(10), source_location VARCHAR(10), destination_location VARCHAR(10), priority VARCHAR(20), created_at TIMESTAMP); CREATE TABLE route_results (result_id VARCHAR(10) PRIMARY KEY, request_id VARCHAR(10), algorithm VARCHAR(30), total_cost FLOAT, total_distance FLOAT, total_time FLOAT, risk_score FLOAT, status VARCHAR(20), created_at TIMESTAMP); CREATE TABLE route_steps (step_id VARCHAR(20) PRIMARY KEY, result_id VARCHAR(10), sequence_no INT, location_id VARCHAR(10));

3. DFD Level 1 — Module Data Flow (Section 5.2)

Operator ↓ [P1 User Validation] ➔ D1: Users ↓ [P2 Incident & Location Manager] ➔ D2: Incidents / Locations ↓ [P3 Graph Builder] ➔ D3: Edges & Topology ↓ [P4 Algorithm Engine] (Dijkstra / Floyd / Bellman-Ford / Prim) ↓ [P5 Route Validator] (Check constraints & blockages) ↓ [P6 Result & Reporting] ↓ Operator (Displays Best Path)

4. DFD Level 2 — Route Planning Process (Section 5.3)

4.1 Read source & destination ↓ 4.2 Load graph from database ↓ 4.3 Evaluate edge status (OPEN / RESTRICTED / BLOCKED) ↓ 4.4 Calculate combined edge cost: Cost(e) = α·Time + β·Dist + γ·Risk + δ·Penalty ↓ 4.5 Initialize distances / priority queue (Min-Heap) ↓ 4.6 Relax candidate edges: if dist[u] + w < dist[v] ↓ 4.7 Destination reached? ├── NO ➔ Continue relaxation └── YES ➔ 4.8 Reconstruct path from predecessors ↓ 4.9 Validate feasibility & constraints ↓ 4.10 Generate final route result & save to database
